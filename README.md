# Práctica de Consumo de APIs
<img width="960" height="504" alt="image" src="https://github.com/user-attachments/assets/1f907fc6-6d07-45f0-89a3-5b030c38063b" />
Este proyecto consiste en el desarrollo de una página web para practicar el consumo de APIs mediante JavaScript. Su objetivo es aprender a realizar solicitudes HTTP, procesar respuestas en formato JSON y mostrar información dinámica en una interfaz web.

La página reúne diferentes funcionalidades que permiten interactuar con servicios externos, como la obtencion de Pokémon aleatoria que mustra un sprite y sus habilidades, la obtención de usuarios aleatorios, muestran plantillas de memes, y un chat con inteligencia artificial donde se evidencia el consumo de API KEYS.

La página web se despliega en Netlify desde el siguiente enlace:
https://pruebaconsumoapis.netlify.app/

También se desplego por medio de GitHub Pages:
https://cristopher-b.github.io/ConsumoAPIs/
